# Auto Management Web v1.5.90 — HSRP Sub Dealer Sections in One Worksheet

- Corrected the HSRP Sub Dealer Excel export based on user clarification.
- All Sub Dealer/Agent records export to one worksheet named `All Sub Dealers`.
- Each Sub Dealer section has a merged, centered, bold title, followed by the same six bold column headings and that dealer's records.
- Sections are separated by a shaded spacer row and clear borders.
- Columns: Chassis Number, Registration Number, Customer Name, Mobile Number, Model, Agent / Sub Dealer Name.
- Current Agent, status and search filters are respected; blank Agent records appear under `Unassigned Agent`.
- Export styling library is loaded from jsDelivr on demand; export requires internet access.
