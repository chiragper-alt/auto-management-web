# v1.7.34 - PDF document storage

- PDF uploads remain PDF.
- JPG/JPEG/PNG/WebP uploads are converted to PDF in-browser.
- Process All & Save stores assigned non-signature documents in local IndexedDB as PDFs.
- Saved document View opens the PDF preview modal with a Print action.
- Signature and generated Form 34 flows are excluded from generic image conversion.
- Word/Excel conversion is not included.

Code-level checks only; browser end-to-end and print validation remain pending.
