# Developer Account Setup

The application now requires the bundled Developer Serial Key before the first Developer account can be created.

1. Open the single Auto Management Web site.
2. Enter the Developer Serial Key from `DEVELOPER_SERIAL_KEY.txt`.
3. Create the Developer account. The Developer ID must be a valid email address.
4. Set an 8+ character password.
5. After setup, use the email + password on the normal Developer login.

The serial activation is stored locally on the device. Resetting the local Developer setup requires the serial key again.
